# Portfolio

Personal portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and GSAP.

## Getting Started

Install dependencies and run the dev server:

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run start` runs the production server.
- `npm run lint` runs ESLint.

## Notes

- Update the project links in `constants/index.ts` with real live URLs before deployment.
- Replace the placeholder social and resume assets in `public/` with final branded files if needed.
